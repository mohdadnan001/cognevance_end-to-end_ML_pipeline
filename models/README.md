# Model artifacts

| File | Description |
|---|---|
| `best_model.joblib` | Selected scikit-learn pipeline (fitted preprocessor + XGBoost model). |
| `keras_model.keras` | TensorFlow/Keras MLP trained for the deep-learning comparison. |
| `preprocessor.joblib` | Fitted `ColumnTransformer` used for Keras inference and analysis. |
| `metadata.json` | Model name/type, tuned threshold, validation/test metrics, feature schema, library versions and dataset metadata. |

These artifacts are generated by `python scripts/run_pipeline.py` and are loaded
by the FastAPI service and the Streamlit dashboard. They are committed to the
repository (total size is small) so the API can run without retraining.

If you retrain, artifacts are overwritten atomically by the training script.
